# vochess
🎙️ Voice Commands: Interact with the chess game using supported spoken commands.

♟️ Interactive Chessboard: Play chess through a digital chessboard.

♙ Legal Chess Moves: Support standard chess rules and valid moves.

🔊 Voice Feedback: Hear spoken game updates when supported.

🌐 Multilingual Support: Planned support for English, Hindi, Mandarin Chinese, Spanish, Standard Arabic, French, German, Portuguese, Korean, and Japanese.

🇮🇳 English Accent Options: Indian, British, and American English voices, depending on browser availability.

♿ Accessibility-Focused Design: Reduce barriers for users who find traditional mouse-and-keyboard interaction difficult.

💻 Web-Based Platform: Designed to run in a modern web browser.
