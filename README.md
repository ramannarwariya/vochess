# ♟️ VoiceChess – Hands-Free Accessible Chess

**Making Chess Accessible to Everyone Through Voice Commands**

🔗 **Live Demo:** [https://vochess.netlify.app/](https://vochess.netlify.app/)

## 🌟 About the Project

VoiceChess is an accessibility-focused chess application designed especially for people with **motor impairments, paralysis, limited hand mobility, or individuals who cannot use their hands to operate traditional input devices.**

Traditional chess platforms require players to use a mouse, keyboard, or touchscreen. This creates barriers for people with physical disabilities.

Our solution is simple: **Play chess using your voice!**

VoiceChess allows users to play chess against an AI or with friends using voice commands in English, Hindi, and Hinglish. It aims to make chess more inclusive, accessible, and enjoyable for everyone.

## 🎯 Problem Statement

People with motor disabilities, paralysis, or limited hand movement often face difficulties accessing traditional computer games.

Most chess applications depend on physical interaction, making independent gameplay challenging for these individuals.

## 💡 Our Solution

We developed VoiceChess, a hands-free chess platform that allows players to control the game through natural voice commands.

Instead of dragging chess pieces using a mouse, users can simply speak their moves.

For example:

- "E2 to E4"
- "E2 से E4"
- "Knight to F3"
- "G1 F3"

The application recognizes the commands and performs the corresponding chess moves.

## ✨ Key Features

### 🎙️ 1. Voice-Controlled Chess

- Play chess without using a mouse or keyboard.
- Move pieces using natural voice commands.
- Supports English, Hindi, and Hinglish commands.
- Type commands as an alternative to speaking.

### 🤖 2. Play Against Computer

- Play against built-in Chess AI.
- Choose AI difficulty levels.
- Practice chess independently using voice commands.

### 🌐 3. Play With Friends

- Play chess with another person.
- Connect two computers using the same Wi-Fi/LAN network.
- Join games using a simple 4-digit room code.
- Supports offline LAN server connectivity.

### 🔊 4. Voice Feedback

- Hear game status and updates.
- Voice readback for improved accessibility.
- Sound effects for a better playing experience.

### ♟️ 5. Additional Chess Features

- Legal move hints.
- Undo moves.
- Flip chessboard.
- New game and draw options.
- Resign option.
- Move history and game records.

### 🧠 6. Improved Voice Recognition

- Checks multiple speech recognition alternatives.
- Handles commonly misrecognized chess coordinates.
- Corrects certain misheard letters and numbers.
- Prevents the microphone from picking up the application's own voice feedback.

## 🛠️ How to Play

**Step 1:** Open the application.

[https://vochess.netlify.app/](https://vochess.netlify.app/)

**Step 2:** Allow microphone access when prompted.

**Step 3:** Select your preferred game mode:

- Play with Computer
- Play with Friend

**Step 4:** Enable Voice Control.

**Step 5:** Speak your chess move.

For example:

- "E2 to E4"
- "Knight to F3"
- "E2 से E4"

**Step 6:** Enjoy playing chess hands-free!

## 🌐 Playing With Friends on LAN

1. Open VoiceChess on the first computer.
2. Select **PC 1: Host Room (White)**.
3. A 4-digit room code will be generated.
4. Open VoiceChess on the second computer.
5. Enter the room code and click Join (Black).
6. Both players can now play together over the same network.
